# Тренажёр: первый срез

HTTP API лабораторного тренажёра и интерфейс на React. Живой контейнер есть у веб-заданий, где навык — сервис. Криптография и проверка исправления идут без контейнера.

Точка входа: `src/index.ts`.

## Что умеет срез

- Команда от одного до четырёх человек. На DevSecOps лимит ровно один. На остальных темах лимит темы, не формат отдельного задания.
- Восемь работ курса. У каждой темы есть домашний пул из seed и очный вариант той же компетенции на другом материале.
- Выдача задания из seed. Наружу уходит условие. Тот же seed даёт тот же вариант, другой seed — другой секрет.
- Автопроверка: «зачтено» или «не зачтено». Сравнение строки, флаг стенда `HITS{...}`, проверка исправления кода и описания сборки. Контейнер запускают веб-задания. Шифры и патч — нет.
- Чужой секрет не зачитывается. Совпадение с секретом другой команды пишется инцидентом с обоими названиями.
- Оценка одной лабораторной берёт очный результат. Весь домашний пул без очной части — 2. Простое очное при всём домашнем пуле — 3. Среднее, сложное с двумя и более подсказками или верный путь без сдачи — 4. Сданное сложное — 5. Тройка и выше только если дома решена хотя бы часть. Итог курса не считается.
- Вход по логину и паролю. Роли: студент, ассистент, автор заданий и преподаватель. Пароль хранится как bcrypt. Преподаватель загружает группу CSV, доступ получают все из файла. Ассистент открывает очную сессию. Автор собирает задание. Студент не читает чужую команду, чужую оценку и чужой пакет.
- Паспорт задания лежит в базе: тема, компетенция, домашний или очный режим, уровень, чекер. Список заданий API читает оттуда.
- Очная сессия: код, таймер от 10 до 20 минут, уровень. Вне такой сессии очное задание не открывается.
- Своя задача сдаётся пакетом: название, описание, флаг, инструкция, лицензия и ссылка или файл. В восемь работ и в оценку лабы пакет не входит.
- Интерфейс: вход, темы, условие, сдача и вердикт. Преподаватель открывает окно темы и очную сессию и видит пакет студента.
- Преподаватель собирает своё задание в интерфейсе: тема, компетенция, домашнее или очное, уровень, условие и чекер (флаг, строка или патч). Секрет флага и строки лежит в паспорте и студенту не отдаётся. Генераторы каталога остаются. Такие задания не входят в шкалу темы.
- Экраны задания разделены: список, карточка, создание и сдача. Студент видит свой вердикт.
- Экраны решений: список и карточка. В карточке кто сдал, какое задание, текст сдачи, вердикт и время. Студент видит только сдачи своей команды.
- Журнал команды: открытие задания, запуск стенда, попытка и подсказка. Подсказка открывается кнопкой, время открытия сохраняется. Лимит попыток задаётся в паспорте. Слишком быстрое решение преподаватель видит в журнале. Студент чужой журнал не видит. Подсветка оценку не меняет.
- Живые стенды веб-заданий: свой контейнер на команду, старт до 30 секунд, студенту только адрес, флаг из seed внутри сервиса. Падение одного контейнера не гасит остальные. Шифры и проверка исправления контейнер не запускают.

## Интерфейс

```bash
cd client
npm install
npm run build
cd ..
export TEACHER_LOGIN=teacher
export TEACHER_PASSWORD=teacher-pass-1
npm start
```

Открыть http://127.0.0.1:3000 . Для правки экрана без сборки: `npm start` в каталоге платформы и `npm run dev` в `client`, затем http://127.0.0.1:5173 .

Живой стенд слушает `127.0.0.1` и нужен запущенный Docker. Образ `trainer-web-stand:local` собирается при первом открытии веб-задания.

## Запуск

Нужны Node.js 22 и PostgreSQL 16.

```bash
npm install
export DATABASE_URL=postgres://trainer:trainer@127.0.0.1:5432/trainer
export TEACHER_LOGIN=teacher
export TEACHER_PASSWORD=teacher-pass-1
npm start
```

`TEACHER_LOGIN` и `TEACHER_PASSWORD` заводят преподавателя при старте, если такого логина ещё нет. Пароль в репозиторий не кладётся.

Postgres из compose: `docker compose up -d` в этом каталоге, затем тот же `DATABASE_URL`.

Слушает порт `3000` (`PORT` и `HOST` меняют адрес).

## Тесты

Тесты ходят в отдельную базу `trainer_test` (`TEST_DATABASE_URL`).

```bash
npm test
```

## Границы среза

Нет HTTPS, метрик, нагрузочного теста, ведомости и итога дисциплины. Криптография и проверка исправления контейнер не запускают.
